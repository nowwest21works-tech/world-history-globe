# 学習ツアー「歴史を旅する」設計

状態：**承認済み（2026-10-31）・実装済み**（PR①）
ねらい：「同じころ、世界では？」と「歴史のつながり」を、地球を巡る体験として届ける。

---

## 1. データ構造（`src/data/tours.json`、型は `src/types/tour.ts`）

```ts
type TourKind = "contemporary" | "connection";                 // 同時代型 / つながり型
type ArcCertainty = "established" | "traditional" | "debated"; // 史実 / 伝承 / 諸説あり

interface TourStep {
  id: string;               // ツアー内で一意
  eventId: string;          // 対象イベント（events.json の id）
  year: AstroYear;          // このステップでスライダーを合わせる年（天文学的年号）
  camera?: { lat: number; lng: number; altitude: number }; // 省略時はイベント地点・既定の高さ
  narration: string;        // 語り文（独自の文章）
  question: string;         // 探究の問い
  arcFrom?: {               // つながり型のみ
    eventId: string;        // 弧の始点となるイベント（ツアーのステップでなくてもよい）
    certainty: ArcCertainty;
    label: string;          // 弧に添える短い説明
  };
}

interface Tour {
  id: string;               // URL にも使う（?tour=paper&step=3）
  title: string;
  kind: TourKind;
  intro: string;            // 導入文
  steps: TourStep[];
  outro: string;            // まとめ
  closingQuestion: string;  // 全体を振り返る問い
  verified: boolean;        // ツアーの文面も人間の確認対象。初期値 false
}
```

### 設計時からの変更点
- `arcFrom` の始点は、設計案の「ステップの id」ではなく **イベントの id** で指定する。ツアーのステップに含まれないイベント（例：ガマの弧の始点「コンスタンティノープルの陥落」）からも弧を引けるようにするため。

### relatedEventIds との関係
- イベント同士の「関係」はイベント側の `relatedEventIds` が持ち、ツアーはそれを使って見せるだけにする。
- 弧を引くには、**到着側のイベントが、始点のイベントの `relatedEventIds` に含まれていること**を条件とし、単体テストで検査する。

### 検査（`src/lib/tours.ts` の `validateTours`、`tests/unit/tours.test.ts`）
- 各ステップの `eventId` と弧の始点が存在する
- 語り文が 40〜180 字、問いが「？」または「。」で終わる
- ツアーの `verified` は false
- 同時代型：全ステップが同じ年で、その年の「同時代」に各イベントが入っている。弧を持たない
- つながり型：年が前に戻らない、各ステップの年がイベントの年代から離れすぎない、2番目以降は必ず弧を持つ

## 2. 2種類のツアー

| 種類 | 年 | カメラ | 弧 |
|---|---|---|---|
| 同時代型 | 全ステップ同じ年に止める | 世界各地を巡る。導入とまとめは引いて見渡す | なし（各地のマーカーを最初から全部出す） |
| つながり型 | ステップごとに進む | 各地点へ移動 | 通ったステップの弧を消さずに積み重ねる |

弧の線種：**史実＝実線（金色）／伝承＝破線（白）／諸説あり＝点線（青）**。地球上では弧の中点にラベルを置き、伝承・諸説ありのときは「伝承：」「諸説あり：」を先頭に付ける。

## 3. 画面上の操作

| 操作 | 内容 |
|---|---|
| 開始 | ヘッダーの「歴史を旅する」→ 一覧（名前・種類・か所数・導入文）→「はじめる」 |
| URL から開始 | `?tour=<id>&step=<n>`（n=0 は導入、1〜N は各ステップ、N+1 はまとめ）。授業でリンクを配れる |
| 進行 | パネルに「はじめに／n / N／まとめ」、語り文、弧の説明、問い（「考えてみよう」）、前へ／次へ。PC は ← → キーでも進める |
| ツアー中 | 自動再生は使えない。地球は自由に回せる。「この地点に戻る」でステップの位置へ戻る。「このできごとの詳細」やマーカーで詳細を開き、「ツアーに戻る」で復帰 |
| 途中で抜ける | ×（または Esc）。その年・その場所のまま自由に見て回れる状態に戻り、URL からツアー指定が消える |

### スマホでの見せ方
- 詳細表示と同じ上下2段（上55%：地球／下45%：ツアーのパネル）。地球の描画領域ごと縮むので、ステップの地点は見えている地球の中央に来る。
- 前へ／次へはパネル下端に固定（高さ44px以上）。
- ヘッダーはボタンが2つ並ぶため、ロゴの文字を視覚上だけ隠す（読み上げ用には残す）。

## 4. ツアー（第1弾・4本）

| id | 名前 | 種類 | 年 | ステップ |
|---|---|---|---|---|
| `bc500` | 前500年頃、世界では？ | 同時代型 | 前500年 | 孔子 → 釈迦 → ダレイオス1世 → クレイステネスの改革 → ペルシア戦争 → ローマ共和政 → オルメカ |
| `paper` | 紙の旅 | つながり型 | 105〜1450年 | 蔡倫 → 曇徴（東へ）→ タラス → バグダードの製紙（**伝承の破線**）→ イベリア半島の製紙 → グーテンベルク |
| `silver` | 銀が世界をめぐる | つながり型 | 1492〜1571年 | グラナダ開城 → コロンブス → ガマ（**諸説ありの点線**、始点はコンスタンティノープルの陥落）→ マゼラン → アステカ征服 → インカ征服 → ポトシ → マニラ・ガレオン |
| `ad800` | 800年頃、世界では？ | 同時代型 | 800年 | カールの戴冠 → アッバース朝とバグダード → 唐 → 平安京 → マヤの古典期 |

- 「銀が世界をめぐる」は、旧案「1492年、世界がつながる」を改名したもの。
- 語り文・問いはすべて独自の文章。ツアーの `verified` は 4本とも false。
- 「紙の旅」のタラス→西方は伝承として扱い、語り文でも「確かな記録は見つかっていない」と明記し、問いで「なぜこの話は広まったのか」を考えさせる。
