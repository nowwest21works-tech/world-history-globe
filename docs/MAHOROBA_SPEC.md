# マホロバ学校との接続 ― 地球儀側 実装指示書

作成：2026-11-09（設計担当：相棒Claude ／ 承認：今西）
実装担当：Claude Code
位置づけ：World History Globe を、MAHOROBA（https://www.mahoroba-office.co.jp/）のマホロバ学校（/b05）の「地球儀の教室」にする。MAHOROBA 側（学校の入口・広場の年代史・賢人対話室からのリンク）は、別の担当が mahoroba-web-current リポジトリで並行して作る。この指示書は**地球儀側だけ**を扱う。

---

## 0. ゴール

1. **年を指定して開ける**：`?year=1989` で、地球儀がその年で開く。MAHOROBA の年代史（1979〜2000年）や賢人（紀元前〜現代）から飛んでくる入口になる。
2. **学校へ戻れる**：地球儀の画面から、マホロバ学校へ戻る道がある。一方通行で外へ出ていくサイトではなく、「まちの中の教室」にする。
3. **年代史の22年に、世界の出来事が少しある**：1979〜2000年の出来事が今は少ないので、数件だけ補う。

---

## 1. 守ること（既存ルールの延長）

- データのルールは `docs/WORKS_SPEC.md`・`docs/JAPAN_SPEC.md` と同じ。画像なし、独自の文章、出典は日本語版ウィキペディア（MediaWiki API で存在と曖昧さ回避でないことを確認）、`verified` はすべて `false`。
- 試作版の帯（PreviewBanner）と `noindex` はそのまま残す。
- `main` へは直接 push しない。ブランチ `feature/mahoroba-school` で作業し、PR を作って止める（マージは今西の GO のあと、相棒が行う）。
- 既存の URL（`?mode=japan`・`?event=`・`?tour=&step=`・`?work=`）の動きを壊さない。

---

## 2. `?year=` で開く

- `?year=N` を受け付ける。**正の数は西暦、負の数は紀元前**（`-470` は「前470年」。0 は無効）。内部の天文学的年号への変換は既存の関数を使う。
- `?mode=japan&year=1868` のように `mode` と組み合わせられる。
- 開いたときの見え方：
  - 年のスライダーが N に合う。
  - その年に近い出来事が見える状態にする（既存の「同じころ、世界では？」の範囲の考え方を再利用する）。**詳細パネルは自動では開かない**（どれを開くかは訪れた人が選ぶ）。
  - 範囲外の値・数字でない値は無視して、いつもの初期表示にする。
- `?event=` と `?year=` が両方あるときは `?event=` を優先する。
- 年を動かしたあと、URL を `?year=` に書き換えるかは任意（やるなら `history.replaceState` で、戻るボタンの履歴を増やさない）。

## 3. マホロバ学校へ戻る道

- ヘッダーの端（PC）／メニュー内または画面下の目立ちすぎない位置（スマホ）に「🏫 マホロバ学校へ」を置く。
- リンク先：`https://www.mahoroba-office.co.jp/b05#school-globe`
- 地球儀や地図の操作の邪魔をしないこと。スマホ幅 390px で、地図・詳細パネル・試作版の帯と重ならないこと。
- 新しいタブでは開かない（同じタブで戻る）。

## 4. 1979〜2000年の世界の出来事を補う（最大8件）

- 年代史の22年（1979〜2000年）に、今は世界の出来事が少ない（改革開放1978・ベルリンの壁1989・ソ連解体1991・WWW1991・EU1993・アパルトヘイト終結1994・WTO1995程度）。
- 候補（確かめられたものだけ。数は8件まで）：イラン革命（1979）、チェルノブイリ原発事故（1986）、天安門事件（1989）、湾岸戦争（1991）、ルワンダ虐殺（1994）、香港返還（1997）など。
- 既存のイベントと重複しないこと。`docs/COVERAGE.md` を更新する。
- 確かめられなかった記述は文面から外す（前回までと同じ）。

## 5. テスト

- 単体：`?year=` の解釈（正・負・0・範囲外・数字以外）、`mode` との組み合わせ、`?event=` が優先されること。
- 操作テスト：`?year=1989` で開いて年が合うこと、`?mode=japan&year=1868`、学校へ戻るリンクが PC とスマホ幅 390px で見えて押せること。
- `npm run typecheck` / `npm test` / `npm run build` / `npm run test:e2e` / `npm run check:sources` がすべて通ること。
