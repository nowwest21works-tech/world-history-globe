状態：**承認済み（2026-10-31）**

## 1. 運用（1回20件以内）

毎回、次の条件をすべて通す。

1. 追加する候補を今西が確定する（または承認済みの計画に従う）
2. 出典記事が存在し、曖昧さ回避ページでも転送ページでもないことを MediaWiki API で確認する
3. 概要と注記を独自の文章で書く（ウィキペディアの転載・言い換えはしない。リンクの掲載のみ）
4. `verified: false` のまま追加する
5. 出典記事の導入部と照合し、結果を `docs/VERIFICATION.md` に追記する（一致／要確認／判断不能）
6. 単体テスト（データ整合性・「同時代」帯が常に2件以上）と操作テストを通し、PR を作る
