# 作品データ（`src/data/works.json`）の運用ルール・照合記録・選定基準

「作品から探す」で使う作品データの決まりごとと、ウィキペディア日本語版との照合の記録です。
設計と実装の指示は [WORKS_SPEC.md](WORKS_SPEC.md)、型定義は `src/types/work.ts`、検証は `src/lib/validate.ts` の `validateWorks` です。

> ⚠️ 36本すべて **未検証（`verified: false`）** です。作品情報（作者・初出年・メディア展開・年齢区分・公式サイト）と、出来事との紐づけ・時代設定・問いの文面は、人間が確認したものだけ `true` にします。

---

## 1. 運用ルール

### 守ること
- **画像を一切使わない。** 書影・ポスター・スチル・キャラクター画像は、引用の形であっても載せない。作品はテキスト（題名・作者・年・ラベル）だけで表す。`validateWorks` は `image` / `cover` / `thumbnail` / `poster` などのキーがあるとエラーにする。
- **文章はすべて独自の文章。** `setting` / `eraNote` / `hook` / `gapQuestion` / `contentNote` は、公式サイトやウィキペディアの紹介文・あらすじ・キャッチコピーを転載・言い換えしない。セリフ・歌詞も引用しない。
- **作品の評価を書かない。**「名作」「面白い」などは書かない。
- **史実との違いは断定せず、問いにする。**「この作品は史実と違う」とは書かず、`gapQuestion` で問い、答えは出典・教科書へ向かわせる。
- **出典（`sources`）はウィキペディア日本語版の記事 URL のみ**、MediaWiki API で記事が存在し、曖昧さ回避・転送ページでないことを確かめたものだけ。`npm run check:sources` でイベントと作品の両方を再確認できる。
- **`officialUrl`** は出版社・配給会社・放送局・製作委員会などの公式ページで、実在を確かめたときだけ。配信サービスへの直リンクはしない。確かめられなければ空文字。
- **`rating`** は映倫区分・CERO 区分などの**公式な区分を確かめられた場合だけ**。推測では入れない。許可する値は `G` / `PG12` / `R15+` / `R18+` / `CERO A`〜`CERO D` / `CERO Z`（`src/lib/works.ts` の `RATING_ALLOWLIST`）。
- **確かめられない情報は推測で埋めず、空欄のまま**にして、この文書の「未確認の項目」に記録する。

### データの決まり
| 項目 | 決まり |
|---|---|
| `id` | kebab-case・一意 |
| `media` | 1つ以上。`manga` `anime` `film` `drama` `novel` `stage` `game` のいずれか（表示：漫画・アニメ・映画・ドラマ・小説・舞台・ゲーム） |
| `fidelity` | `historical`（史実ベース）／`historical-fiction`（史実の枠に創作）／`inspired`（時代を借りた創作） |
| `firstReleased` | 原作の連載開始・初公開などの西暦年（1900〜今年の整数） |
| `era` | 作品が描く時代（天文学的年号。前1年＝0）。`to >= from` |
| `eventIds` | 1件以上・重複なし・`events.json` に存在する |
| 時代のずれ | 紐づく各イベントの期間（start〜end）と `era` が、重なるか端どうしの差が50年以内 |
| `verified` | 初期値はすべて `false` |

### 確認（verified を true にする）手順
1. 作品情報（作者・初出年・メディア展開・年齢区分・公式サイト）を、出版社・配給会社などの一次情報で確かめる。
2. 紐づくイベント、`era` と `eraNote`、`setting`、`gapQuestion` が妥当かを確かめる（問いが答えを決めつけていないか、史実の側に立って検証できるか）。
3. 問題がなければ `verified` を `true` にする（UI の「未検証」バッジが「確認済み」に変わる）。

## 2. 選定基準（シード36本）

- **高校生が知っている、または授業で紹介しやすい作品**（漫画・アニメ・映画・ドラマ・小説・舞台）。
- **既存のイベントに紐づけられる作品だけ**を入れる。紐づけるイベントがない時代の作品は、[WORKS_SPEC.md](WORKS_SPEC.md) の 5.1（第2段階）のとおり、先にイベントを追加してから登録する。
- **地域と時代の偏りを抑える**：古代オリエント・中国・インド・地中海・モンゴル・ヨーロッパ・アメリカ・日本・アフリカに分散させる。
- **「史実との距離」の3種をすべて含める**：史実ベースの伝記映画から、時間移動や伝奇の作品まで。
- **描写の強い作品は `contentNote` で傾向を示す**（独自の文章）。授業で扱うかどうかの判断は教員に委ねる。

## 3. 照合記録（2026-11-05）

### 方法
- 対象：`works.json` の36本の、作者名（`creators`）・初出年（`firstReleased`）・主なメディア展開（`adaptations` と `media`）。あわせて `rating` と `officialUrl` を探した。
- 照合先：各作品のウィキペディア日本語版記事。MediaWiki API の抜粋機能（導入部）と、記事冒頭の節のウィキテキスト（情報ボックスを含む）を取得した。導入部にない展開・年齢区分は、記事本文を全文検索（`insource:`）して該当箇所を確かめた。
- 作業環境からは ja.wikipedia.org へ直接接続できないため、イベントの出典確認（README）と同じく **Exa の Web 取得機能経由で MediaWiki API を呼んだ**。
- 記事の実在確認：出典に入れた46記事すべてを `scripts/check-sources.mjs` と同じクエリ（`action=query&redirects=1&prop=pageprops&ppprop=disambiguation`）で確かめ、**存在しない・転送・曖昧さ回避は0件**だった。
- 公式サイト：候補 URL を Exa で取得し、ページの題名・内容が公式サイト（製作委員会・配給会社・放送局・スタジオ）であることを確かめたものだけを入れた。
- **この作業では verified を true にしていない。**

## 4. 日本史モードとの紐づけ（2026-11-06・PR①）

- 日本が舞台の6作品（『阿・吽』『沈黙 -サイレンス-』『坂の上の雲』『ゴールデンカムイ』『この世界の片隅に』『はだしのゲン』）が紐づく出来事（平安京・江戸幕府の対外政策・明治維新・日露戦争・原爆投下など）は、世界と日本の両方の地図に出る共有イベントにしたため、日本モードでもそのまま「この時代を描いた作品」に出る。
- 『坂の上の雲』は、ウィキペディア日本語版の作品記事が日清戦争を経て日露戦争に至るまでを扱うとしていることを確かめ（本文検索）、日本側の「日清戦争」（`jp-sino-japanese-war`）にも紐づけた。
- 作品データの整合性チェック（`validateWorks`）は、世界・日本の両方のイベントを参照先として確かめるようにした。
- 新しい日本史の作品は第2段階（PR③）で入れる（指示書 6章）。第1段階では作品データを新しく作っていない。
