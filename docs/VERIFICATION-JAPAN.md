- 実施日：2026-11-05〜11-06。回ごとに「内容」欄の先頭に【第1回】〜【第4回】と表示する
- 照合した範囲：各出典記事（ウィキペディア日本語版）の**導入部（冒頭の要約部分）**。MediaWiki API の抜粋機能（`prop=extracts&exintro=1`）で記事ごとに冒頭約700字を取得した。導入部にない年・地名は、記事本文の全文検索（`list=search` の `insource:`）で該当箇所を確かめ、その場合は「内容」欄に「本文」と書いた。
- 作業環境から ja.wikipedia.org へ直接接続できない（プロキシが 403 を返す）ため、世界史の照合と同じく **Exa の Web 取得機能を経由して MediaWiki API を呼んだ**。複数の記事を1回の API 呼び出しでまとめて取得し、返ってきた JSON の `title` と `pageid` で記事ごとに対応を確かめた（キャッシュの取り違えがないかを、記事名と本文の内容が一致することで確認した）。
- 記事の実在確認：出典に入れたすべての記事を `scripts/check-sources.mjs` と同じクエリ（`action=query&redirects=1&prop=pageprops&ppprop=disambiguation`）で確かめ、**存在しない・転送・曖昧さ回避は0件**だった。確認の途中で、候補だった「勘合貿易」は「日明貿易」への転送、「朱印船貿易」は「朱印船」への転送、「鷹島」は曖昧さ回避と分かったため、出典には使っていない（転送先の記事名で載せた）。
- 照合した観点：**年代・場所・概要**の3点。
- **この作業では verified を true にしていない。** 全件 `verified: false` のまま。
